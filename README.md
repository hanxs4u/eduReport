# EduReport

React + Vite + TypeScript + Tailwind CSS 기반 프론트엔드 프로젝트입니다.

## 기술 스택

- **Framework**: React 19 + Vite 8
- **Language**: TypeScript
- **Styling**: Tailwind CSS v4 (`@tailwindcss/vite`)
- **Linter**: Oxlint

## 시작하기

```bash
# 의존성 설치
npm install

# 개발 서버 실행
npm run dev

# 프로덕션 빌드
npm run build

# 린트 검사
npm run lint
```
